# Todo List Manager (CLI)

A simple and interactive command-line interface (CLI) to manage your daily tasks. Tasks are automatically saved to `todo.json`.

## Features

- View all pending and completed tasks.
- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Persistent JSON storage.

## How to Run

```bash
python todo_cli/main.py
```
*(No external dependencies required — runs using Python's standard library.)*
