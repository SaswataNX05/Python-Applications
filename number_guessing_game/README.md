# Number Guessing Game (GUI)

A modern desktop GUI number guessing game built using [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter).

## Features

- Sleek modern dark mode UI.
- Interactive feedback with proximity badges ("Burning Hot!", "Getting Warm", "Cold").
- Direction hints ("Too High!", "Too Low!").
- Lives system with heart indicators.
- Guess history tracking.

## Requirements

Install dependencies using the root `requirements.txt`:
```bash
pip install -r requirements.txt
```
*(Or install `customtkinter` directly: `pip install customtkinter`)*

## How to Run

```bash
python number_guessing_game/main.py
```
